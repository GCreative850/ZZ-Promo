# ZZ OS

Phone-first business dashboard for building a simple recurring promo service.

## What is built

- Mobile dashboard
- AI message generator
- Lead/client pipeline
- Monthly recurring revenue tracker
- Payment message generator
- Settings saved on-device with localStorage
- Single-file static website at `index.html`

## How to make it live from your phone

### Option 1: GitHub Pages
1. Open the repo on GitHub.
2. Tap **Settings**.
3. Tap **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch: `main` and folder: `/root`.
6. Save.
7. GitHub will give you a live link.

### Option 2: Vercel
1. Go to Vercel.
2. Import this GitHub repo.
3. Deploy.

## Install on iPhone

Open the live link in Safari, tap Share, then tap **Add to Home Screen**.
